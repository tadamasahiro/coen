# ひとことメモ（公開練習用サンプル）

アプリがない方向けのサンプルです。今日の手順で「点検 → 公開」まで進めてください。
データベースは使っていないので、手順②（Supabase）は飛ばしてOKです。

## 手順①：AIにレビューさせる
このフォルダでClaude CodeやCodexを開き、次を貼ってください。

このアプリを一般公開する前提で、セキュリティレビューをしてください。
特に次の3点を、ファイル名と行を示して報告して。
1. APIキーやパスワードがコードに直書きされていないか
2. 認証や権限チェックが抜けている画面・APIがないか
3. パスワードや個人情報を自前で保存していないか
見つかったら、直し方を提案して。私が確認してから修正を進める。

→ 見つかったものを、AIと一緒に直してください（ヒント：2つあります）。

## 手順③：公開する（Vercel）
1. 「このフォルダをGitHubの新しいリポジトリにpushして」とAIに頼む
2. vercel.com にGitHubでログイン → Add New → Project → リポジトリを選ぶ
3. 設定は変えずに Deploy（ビルド不要の静的サイトです）
4. できたURLを開き、右クリック →「検証」→ Sources で、キーが見えないことを確認

## 手順④：AI機能
このサンプルにはAI機能はありません。
